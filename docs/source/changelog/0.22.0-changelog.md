# v0.22.0

Date
: October 06, 2026


## What's Changed
### Breaking Changes 🚨
* Introduce a `Manager` to coordinate the render flow by {user}`behackl` in {pr}`4916`
* Rework output configuration options and how they are consumed by {user}`behackl` in {pr}`4966`
* Refactor media output path resolution and remove the `--custom_folders` CLI flag and config option by {user}`behackl` in {pr}`4969`
* Move video segment encoding to a dedicated module and detach `SceneFileWriter` from renderer state by {user}`behackl` in {pr}`4976`

### Enhancements 🚀
* Improve the error message of `throw_error_if_no_points` and raise `ValueError` instead of `Exception` by {user}`smmariquit` in {pr}`4927`
* Add tests verifying that updaters affect their mobjects by {user}`nikolajmunk` in {pr}`5000`
* Add a `key` parameter to `list_update` and `list_difference_update` to support unhashable elements by {user}`nikolajmunk` in {pr}`4975`

### Bug Fixes 🐛
* Fix OpenGL-specific code paths that were skipped because renderer comparisons against the string `"opengl"` never matched by {user}`pjfo` in {pr}`4929`
* Fix mobject duplication during animations by treating ancestors of moving mobjects as moving by {user}`nikolajmunk` in {pr}`4936`
* Allow `Graph` and `DiGraph` to be initialized without vertices by {user}`christopher-hampson` in {pr}`4946`
* Fix singular/plural form of "submobject(s)" in `VGroup.__str__` by {user}`nikolajmunk` in {pr}`4950`
* Fix right-bounds check in `OpenGLMobject.is_off_screen` by {user}`GniLudio` in {pr}`4953`
* Fix `OpenGLMobject.stretch_to_fit_depth` stretching along the wrong dimension by {user}`GniLudio` in {pr}`4955`
* Fix `OpenGLMobject.get_boundary_point` by {user}`GniLudio` in {pr}`4956`
* Restore renderer class bases when updating the config from another `ManimConfig` by {user}`emerardd` in {pr}`4958`
* Skip hidden files and tolerate vanishing files when cleaning the partial movie file cache by {user}`changsheng0804-blip` in {pr}`4954`
* Fix `LaggedStartMap` unpacking submobjects when using the default `arg_creator` by {user}`SAY-5` in {pr}`4965`
* Fix flaky `ConvexHull` example in the rendered documentation by {user}`behackl` in {pr}`4967`
* Preserve the layout of `MathTypst` capture groups by {user}`behackl` in {pr}`4960`
* Fix `normalize` raising an error instead of returning the fallback vector for zero-norm vectors by {user}`nikolajmunk` in {pr}`5001`
* Fix `is_closed` misclassifying closed curves in negative coordinate space by {user}`Osamaali313` in {pr}`5010`
* Fix `angle_axis_from_quaternion` returning the inverse rotation for angles greater than π by {user}`dylanpulver` in {pr}`4980`
* Fix `LineJointType.AUTO` and `CapStyleType.AUTO` inheriting the previous mobject's style in the Cairo renderer by {user}`RizgarOzan` in {pr}`5016`
* Fix `BarChart` ignoring `include_numbers` in `y_axis_config` by {user}`RizgarOzan` in {pr}`5015`
* Fix graph label placement and coordinate conversion on logarithmic axes by {user}`GreedyC` in {pr}`5039`
* Fix SVG shapes with `stroke="none"` getting a white outline by {user}`RizgarOzan` in {pr}`5036`
* Fix `color` argument of `Text` and `MarkupText` not being applied to the mobject itself by {user}`webzuweb` in {pr}`5017`
* Fix rendering WebM videos with sound when PyAV has no libvorbis encoder by {user}`Darkslayer3324j` in {pr}`5025`
* Fix `ThreeDScene.set_camera_orientation` with the OpenGL renderer by {user}`Smail` in {pr}`5040`

### Performance ⚡
* Speed up `list_update` and `list_difference_update` by using a set for membership checks by {user}`nikolajmunk` in {pr}`4939`
* Speed up redundancy removal in `get_family` and fix families containing loops by {user}`GniLudio` in {pr}`4947`
* Improve speed and robustness of `Mobject` and `OpenGLMobject` add/remove operations by {user}`nikolajmunk` in {pr}`4957`
* Bound the encoder frame queue when rendering without parallel encoding to limit memory usage by {user}`pizzaburgare` in {pr}`5049`

### Documentation 📚
* Mention ruff as formatter and linter in the documentation by {user}`nikolajmunk` in {pr}`4978`
* Add guidance on installing the C++ Build Tools on Windows by {user}`SR0725` in {pr}`4982`
* Add missing module reference for Typst mobjects by {user}`behackl` in {pr}`5007`
* Add instructions for the optional Typst installation by {user}`aryansk` in {pr}`4986`
* Update the testing guide by {user}`cqxswbc2` in {pr}`4991`
* Improve the documentation of `TangentialArc` by {user}`henrikmidtiby` in {pr}`5046`

### Code Quality & Refactoring 🧹
* Replace deprecated `np.sum` calls on generators, fixing a `TypeError` with the OpenGL renderer by {user}`christopher-hampson` in {pr}`4962`
* Fix the `redirections` parameter of the `deprecated_params` decorator by {user}`GniLudio` in {pr}`5028`

### Type Hints 📝
* Use `ParamSpec` in deprecation decorators to preserve signatures of decorated callables by {user}`GniLudio` in {pr}`4988`
* Add type hints to `vector_field.py` by {user}`henrikmidtiby` in {pr}`5030`

### Dependencies 📦
* Update ManimPango dependency to version 0.7.0 by {user}`naveen521kk` in {pr}`5041`
* Update Tornado, Jupyter, and virtualenv dependencies by {user}`behackl` in {pr}`5047`
